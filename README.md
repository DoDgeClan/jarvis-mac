# Jarvis for Mac — by erkaskul

[Download Jarvis Mac 2.1.4](https://github.com/DoDgeClan/jarvis-mac/releases/download/v2.1.4/Jarvis-Mac-2.1.4.zip)

Extract the entire ZIP and open Jarvis.app. Node.js/npm is required; the existing Mac launcher installs Electron on first launch.

English is the default language. Change language and save your Gemini, OpenAI or Claude API key in Settings.

Version 2.1.4 retains the original orb composition with smoother motion, high-DPI edges and softer audio-reactive glow. Expand **Vision & gestures** to share a selected screen for AI analysis or enable local camera hand tracking. Both features are off by default. Pinch toggles the microphone; an open palm stops the response. Optional observation sends one image every 12 seconds. Camera frames stay local; screen snapshots go to your selected AI provider. AI and voice usage may cost extra.

37 automated tests passed. UI and local hand-model initialization were checked. Live webcam tracking, paid vision calls and native Mac launch have not been fully hardware-tested. The Mac app is not signed or notarized.

Full app code, required hand-tracking files and instructions are inside the ZIP. [Release details](https://github.com/DoDgeClan/jarvis-mac/releases/tag/v2.1.4).
