# Jarvis MacBook — erkaskul

A separate repository for the supplied macOS application archive.

## Download

**[Download Jarvis for MacBook — ZIP](https://github.com/DoDgeClan/jarvis-mac/releases/download/v2.1.1/Jarvis-Mac.zip)**

[Release page](https://github.com/DoDgeClan/jarvis-mac/releases/tag/v2.1.1)

1. Extract the entire ZIP.
2. Read `Instructions/INSTRUCTIONS - READ FIRST.txt`.
3. Install Node.js for macOS if it is not already installed. This launcher uses npm to prepare its Electron runtime on first launch; an internet connection is required.
4. The application is `MacBook Jarvis/Jarvis.app`.
5. Enter your AI-provider and optional ElevenLabs keys inside **Settings → API keys**, then select the matching AI provider.

The supplied ZIP is uploaded unchanged. Archive integrity was checked. Actual launch on macOS, signing and provider access have not been tested here.

GitHub’s **Source code** downloads contain this repository, not the application ZIP. AI and voice services may charge for usage. Keep API keys private.
